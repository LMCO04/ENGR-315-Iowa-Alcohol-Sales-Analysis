## Motivation For This Analysis
### The following is an analysis of a dataset containing alcohol purchases in stores with Class E liquor licenses in the state of Iowa. The link to the website containing the research is conducted is: 
[State of Iowa - Iowa Liquor Sales, 2021](https://catalog.data.gov/dataset/iowa-liquor-sales-2021?from_hint=eyJxIjoiTGlxdW9yIn0%3D)
### This data was collected through inventory tracking and in-store record-keeping that is reported to the government. The contents of this file include the date of the alcohol purchase, the location where it occurred, and what type of alcohol it is, including brand, volume, and cost. This information can be used to determine how citizens of Iowa spend their weekends or time celebrating, what they prefer to drink, and how much it costs them to do so.
